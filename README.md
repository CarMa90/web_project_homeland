# Tripleten web_project_homeland

## De patria a patria

Este es un sitio web creado para mostrar una galería de imágenes de los lugares de donde provienen las personas involucradas con TripleTen los cuales se encuentran alrededor del mundo y ese es el motivo del título “De patria a patria”.

Para el diseño de este sitio web se utilizaron html y css, el objetivo de este proyecto es practicar el uso de medidas responsivas y consultas de medios para que el contenido de la página se adapte al tamaño de pantalla desde el cual el usuario la visite.

[Visitar sitio web](https://carma90.github.io/web_project_homeland)
